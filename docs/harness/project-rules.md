# 프로젝트 규칙 — PTK_V2_FE

> 범위: **FE 전용**. 출처 태그(`[U]` `[A]` `[D]`)는 `README.md` 참고. 날짜는 사용자가 해당 지시를 한 대화 시점이다.

## 1. UX · 워크플로우 원칙

- **FE-1 [U 2026-11-25]** 기획자가 **설정 → 조사 계획 → 자료 수집 → 검토·시사점 → 팩트북 출력(PPTX)** 흐름을 끊김 없이 밟도록 설계한다. 각 단계에서 기획자가 무엇을 보고 결정해야 하는지 명확히 노출한다(조사 항목 선택, 수집 인덱스·원문·근거 문장 확인, 기획자 코멘트 작성 및 반영 여부, 개별 클릭이 아닌 **일괄 채택/제외·재시도**).
- **FE-2 [U 2026-11-25]** 지정된 워크스페이스 UX 레퍼런스의 작업 흐름을 따르되, UI 디자인은 PTKOREA 고유 브랜드 시스템을 적용한다.
- **FE-3 [U 2026-11-25]** API 명세서(`PTK_V2_BE` 의 `docs/API_SPEC.md`)를 기준으로 프런트를 설계·연동한다.
- **FE-4 [U 2026-11-27]** 수정을 진행하면서 **사용자 UX가 지저분해지면 안 된다.** 처음 보는 사람도 쉽게 사용할 수 있어야 한다.
- **FE-5 [U 2026-11-25]** 네트워크·요청 불안정으로 **버튼 무반응·오류·빈 장표**가 발생하지 않게 **상태 관리, 중복 클릭 방지(`Idempotency-Key` / AsyncActionButton), 명시적 피드백(`ErrorEnvelope` 기반 토스트/모달), 사전 QC 확인 화면**을 제공한다.

## 2. 비주얼 · 디자인 규칙 [U 2026-11-27]

- **FE-6 [U 2026-11-27]** **색상 · 모드**: 자사 브랜드 컬러 시스템을 가져오되 **배경은 라이트 모드(`#FFFFFF` / `#FAFAFA`)**, **블랙(`#111111`)을 메인 컬러**로, 주황(`#E9501F`)은 포인트 컬러로만 절제해 사용한다.
- **FE-7 [U 2026-11-27]** **아이콘**: `https://lucide.dev/icons/` (`lucide-react`) 에 있는 아이콘만 사용한다.
- **FE-8 [U 2026-11-27]** **레이아웃**: 모바일 앱 같은 UI 를 지양하고 **데스크탑 웹 앱/스튜디오 형태**로 만든다. 투박한 대시보드 카드 나열 형태를 쓰지 않는다.
- **FE-9 [U 2026-11-27]** **모서리(Border Radius)**: 너무 딱딱하지도, 너무 둥글지도 않은 **중간 정도의 균형 잡힌 라운드**(`6px / 8px / 12px`)로 통일한다 (`design-tokens.md`).
- **FE-10 [U 2026-11-27]** **상단 헤더 브랜드**: 기존 아이콘과 프로젝트 타이틀을 없애고 제목 자리에 **`Division 4`** 만 적는다.
- **FE-11 [U 2026-11-27]** **웹 UI ↔ PPTX 포맷 일관성**: 웹 장표 스튜디오와 내보낸 PPTX 결과물의 디자인 포맷(컬러·폰트 위계·그룹 차트 등)이 일정해야 한다.

## 3. 뷰어 · 탐색 화면 세부 규칙 [U 2026-11-27]

- **FE-12 [U 2026-11-27]** **근거 원문 뷰어**: 마크다운(헤더·목록·표·굵기·각주 등)을 깨지지 않게 정상 렌더링하고 근거 문장 하이라이트를 유지한다 (`MarkdownContent.tsx` + `SourceViewerDrawer.tsx`).
- **FE-13 [U 2026-11-27]** **SNS 인기 게시물 TOP 5**: 회사별(자사 vs 경쟁사)·플랫폼별(Instagram / YouTube / 협업 등)로 **어디가 누구의 게시물인지 한눈에 구별**되도록 시각적으로 그룹핑한다.

## 4. 보안 · 빌드 안전 규칙 [A 2026-11-27]

- **FE-14 [U 2026-11-28]** 외부 API 키는 백엔드 `.env` 에만 둔다. 또한 두 레포가 PUBLIC 인 만큼 프런트엔드 코드·`.env.local`·문서·이슈·PR 어디에도 API 키, **실제 고객사명, 실측 데이터, 내부 참고 URL 등 기밀 정보를 절대 커밋하지 않는다** (`ai-operating-protocol.md` P-11).
- **FE-15 [A 2026-11-27]** **`next dev` 가 실행 중일 때 `npm run build` 를 동시에 돌리지 않는다** (`.next` 디렉터리 충돌 방지). 검증 시에는 `next dev` 를 잠시 중지한 뒤 `npx tsc --noEmit && npm run build` 를 실행한다 (`verification.md`).
